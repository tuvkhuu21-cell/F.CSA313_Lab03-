## 3. SLO хүснэгт

| Сценарио | SLI | Босго | Цонх |
|---|---|---|---|
| Performance cart | /cart/add latency | p95 < 50 мс | 20 VU, 1 минут |
| Reliability | /pay error rate | < 8% | 20 VU, 1 минут |
| Availability | Амжилттай checks | > 90% | 20 VU, 2 минут |
| Performance report | /report latency | p95 < 450 мс | 20 VU, 1 минут |

### Босго сонгосон үндэслэл

Cart API-д зориудын хүлээлт байхгүй тул 50 мс сонгосон. Pay API ойролцоогоор 5% алдаа гаргадаг учраас 8%-ийн босго тавьсан. Серверийн зогсолтын үед availability 90%-иас дээш байх зорилт тавьсан. Report API-ийн 200–400 мс хүлээлтэд тохируулан 450 мс сонгосон.

### Error budget

2 минут = 120 секунд. Availability SLO = 90%.

120 × (1 − 0.90) = **12 секунд**.

Хүсэлтээр тооцсон error budget-ийг Chaos тестийн дараа бодит гаралтаас гаргана.
